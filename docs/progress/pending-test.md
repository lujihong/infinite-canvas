# 待测试

## 预计积分与本人价格

- 请求级报价通过本人身份向中转站无扣款端点获取quota，按钱包口径quota/quota_per_unit×10换算；显示预计值，不把预扣或未来用量当最终账单。
- 画布图片/全景/视频/音频/文本/配置节点、独立生图三布局与重试、视频各布局和可灵侧栏、工作流单图/系列/提示词/草稿均接入对应报价。Agent整轮计划和局部蒙版生成若参数尚未完整则明确不能提前给出总额，不猜单价。
- 固定按次图片、无参考视频且明确时长/分辨率的Doubao估算可给预计积分；实际token、多输入视频用量、未支持的协议/元素组合保留usage_required或missing，不冒充免费。
- 价格按身份/渠道/参数变化失效，取消迟到响应，最多四个并发；外部自有渠道不借用本站个人报价。单位价以积分显示，币种展示汇率不参与积分账本换算；上游真实零余额不再回退旧余额。
- 已通过79项前端回归、类型检查、两仓Go全包、报价HTTP无扣款/无任务测试、隔离PostgreSQL真实模型参数矩阵及账本不变检查。生产浏览器验收与最终发布证据见发布记录。

## 失败节点显示优化

- 图片、视频和音频失败节点改为尺寸内的纵向布局，正文独立滚动，操作区换行；移除失败状态的底部渐变遮罩。
- 人物隐私与内容审核错误提供中文说明，不将 AI 生成来源视为免审，也不把虚拟人物引导为真人活体认证。
- 错误详情弹窗保留完整原文，可滚动阅读、复制；查看与复制不触发重试。批次失败也保留检查参考入口。
- 已通过错误分类、超长原文完整显示/复制和操作事件测试，以及类型检查、生产构建；真实浏览器像素边界验收单独记录，不将 jsdom 当布局实测。

## 移动云素材与视频任务来源（已发布，真实授权生成待验）

- 画布和视频页保存素材 URI 与渠道字段；普通媒体替换清除旧素材身份、任务和批次字段。失败结果的修复入口操作参考输入，保留原失败结果，不自动重试生成。
- 我的素材保存并恢复媒体引用身份，移动云素材不再按旧 storageKey 恢复普通文件。
- 素材渠道查询按用户隔离，渠道缺失或失败时禁用认证和上传；上传及创建素材透传明确 channel_id。
- 视频任务创建前保存来源类型、网关地址与绑定用户；轮询和下载验证原来源，缺少快照或绑定变化时明确失败，不切到本地首个渠道。
- 官方网关视频请求保留统一 /videos 路径，不按 Seedance 模型名改为原厂路径。
- 已执行工作台 Go 全包测试、32 项定向前端测试、TypeScript 检查和 Next webpack 生产构建。真实 React/Ant Design 菜单事件测试确认仅本地菜单项触发文件选择事件；生产浏览器已验证图片替换菜单与移动云渠道加载。新增音频菜单的生产浏览器验收受浏览工具决策超时影响，未计通过。
- 对抗复核发现的非官方渠道协议/Key漂移已用任务私有指纹拦截；官方同用户令牌轮换允许。Gemini内容下载校验与渠道同源并禁止跳转，测试确认不向外源发送凭据。
- 当前发布范围为现有单移动云：渠道配置固定模式保留原凭据，禁止跨渠道复用；它不等同于供应商账号核实。内蒙真实凭据到位后另做多渠道验收，不作为本批上线前提。
- 构建已采用 Next 单工作线程、1000MiB Node 堆与 Go 单并发；服务器 BuildKit 容器需额外设置真实内存/CPU限制和临时swap，不能只依赖 docker build 参数。
- 本地两端 Go 全包、网关76项及工作台32项定向前端测试通过。工作台隔离候选首页/设置API已通过，生产切换与功能验收记录由本轮发布报告记录。真人H5授权及真实计费生成未自动执行。
- 画布音频节点已补齐 AICC、我的素材、本地三来源替换菜单，需在浏览器验证音频节点点击后先出来源菜单，确认只有本地项打开系统文件框。
- 音频参考链路已支持连接音频节点：视频生成会按当前模型协议传递音频参考；独立音频生成仅 `mimo-v2.5-tts-voiceclone` 将其作为声音样本，Gemini/GLM/Grok 及普通预设音色不接收参考音频。需在不收费的隔离或可控测试条件下验证请求体与错误提示。
- SQLite 维护工具已通过 16 项合成测试：WAL 提交数据恢复、任意媒体子目录、同秒备份不覆盖、含引号路径、恶意归档/链接拒绝、损坏归档与失败清理。该工具不适用于生产 PostgreSQL；生产两库已分别恢复到断网限资源容器并逐表读取（网关45表，工作台18表），验后清理临时容器。
- 发布入口 `scripts/release-workbench.sh` 将本地已核验镜像解析为 sha256 ID，拒绝 latest，禁止部署时拉取镜像；需显式配置项目名与资源额度。HTTP探针只证明Next到Go代理链存活，不等同于业务readiness。
- 音频参考新增行为回归：画布非克隆模型拒绝录音参考，原选声音断开不自动替换，代理及MiMo原生路径均不静默丢弃参考。移动云素材不经预览URL转发给其他平台克隆；原始录音在Base64编码前限制7.5MiB。音频已接通存素材入口。
- 线上公开模型清单暂未提供TTS/VoiceClone型号，未伪造可用模型；真人音色相似度与实际上游生成尚未验证。持续资源限额校准、持久swap与宿主磁盘告警不属于本次已验证项。
