# 待测试

## 移动云素材与视频任务来源（未发布）

- 画布和视频页保存素材 URI 与渠道字段；普通媒体替换清除旧素材身份、任务和批次字段。失败结果的修复入口操作参考输入，保留原失败结果，不自动重试生成。
- 我的素材保存并恢复媒体引用身份，移动云素材不再按旧 storageKey 恢复普通文件。
- 素材渠道查询按用户隔离，渠道缺失或失败时禁用认证和上传；上传及创建素材透传明确 channel_id。
- 视频任务创建前保存来源类型、网关地址与绑定用户；轮询和下载验证原来源，缺少快照或绑定变化时明确失败，不切到本地首个渠道。
- 官方网关视频请求保留统一 /videos 路径，不按 Seedance 模型名改为原厂路径。
- 已执行工作台 Go 全包测试、32 项定向前端测试、TypeScript 检查和 Next webpack 生产构建。真实 React/Ant Design 菜单事件测试确认仅本地菜单项触发文件选择事件；生产浏览器尚未验收。
- 对抗复核发现的非官方渠道协议/Key漂移已用任务私有指纹拦截；官方同用户令牌轮换允许。Gemini内容下载校验与渠道同源并禁止跳转，测试确认不向外源发送凭据。
- 当前发布范围为现有单移动云：渠道配置固定模式保留原凭据，禁止跨渠道复用；它不等同于供应商账号核实。内蒙真实凭据到位后另做多渠道验收，不作为本批上线前提。
- 构建已采用 Next 单工作线程、1000MiB Node 堆与 Go 单并发；服务器 BuildKit 容器需额外设置真实内存/CPU限制和临时swap，不能只依赖 docker build 参数。
- 本地两端 Go 全包、网关76项及工作台32项定向前端测试通过。工作台隔离候选首页/设置API已通过，生产切换与功能验收记录由本轮发布报告记录。真人H5授权及真实计费生成未自动执行。
